# 브릿지 커피 디지털 메뉴판

손님이 테이블의 QR코드를 찍으면 휴대폰으로 보게 되는 메뉴판 웹페이지예요.
파일은 `index.html` 하나뿐이라서, 별도 설치 없이 바로 열어볼 수 있어요.

## 주요 기능
- **카테고리 버튼**: 전체 / 커피 / 논커피 / 디저트. 누르면 해당 메뉴만 보여요. 버튼은 스크롤해도 화면 위에 따라와요.
- **시그니처 메뉴**: 사장님이 고른 메뉴를 "전체" 화면 맨 위에 따로 모아 보여주고, 카드를 더 눈에 띄게 강조해요.
- **품절 표시**: 품절된 메뉴는 흐리게 보이고 "오늘 품절" 표시가 떠요.
- **전화 걸기 버튼**: 누르면 손님 휴대폰에서 바로 전화가 걸려요.
- **디자인**: 연두색과 크림색, 반투명 카드(글래스모피즘), 휴대폰 화면(폭 390px) 기준.

## QR 코드 만들기 (`qr.html`)
테이블에 붙일 QR 코드를 만들어 주는 페이지예요. `qr.html`을 더블클릭해서 열어요.

1. **메뉴판 인터넷 주소**를 붙여 넣어요. (`https://`로 시작해야 해요)
2. **QR 위에 들어갈 가게 이름**과 **QR 아래 안내 문구**를 적어요. 처음에는 "브릿지 커피", "메뉴판 보기"가 들어 있어요. 가게 이름 칸을 비우면 이름 없이 나와요.
3. "QR 코드 만들기"를 누르면 QR이 크게 나와요.
4. "이미지 다운로드"로 사진(PNG)을 저장하거나, "인쇄하기"로 A4 종이에 크게 인쇄해요.

- **QR 만들기는 인터넷 없이 돼요.** QR 만드는 도구(오픈소스 qrcode-generator, MIT 라이선스)를 파일 안에 넣어 두었어요.
- **QR이 가리키는 메뉴판은 인터넷에 올라가 있어야 해요.** 손님이 QR을 찍으면 그 주소로 접속하기 때문이에요. (예: GitHub Pages)
- 만든 뒤에는 휴대폰 카메라로 찍어서 메뉴판이 열리는지 꼭 확인해 보세요.

## 보는 방법
`index.html` 파일을 더블클릭하면 브라우저에서 열려요.

## 고치는 방법
모든 메뉴 정보는 `index.html` 맨 위쪽 한곳에 모여 있어요. 파일 안에 한국어 설명이 자세히 달려 있으니 먼저 읽어 보세요.

메뉴 한 줄은 이렇게 생겼어요.

```js
{ category: "커피", name: "아메리카노", price: 4500, soldOut: 0, desc: "산미가 적은 고소한 원두" },
```

| 하고 싶은 일 | 방법 |
|---|---|
| 가격 바꾸기 | `price:` 뒤 숫자만 바꾸기 (쉼표, "원"은 쓰지 않아요) |
| 이름·설명 바꾸기 | 큰따옴표 안의 글자만 바꾸기 |
| 메뉴 추가 | 같은 칸의 줄을 복사해서 붙이고 내용 고치기 |
| 메뉴 지우기 | 그 줄을 통째로 지우기 (줄 앞에 `//`를 붙이면 잠시 숨겨져요) |
| 품절 켜기·끄기 | `soldOut: 0`을 `1`로 바꾸기 (판매 중은 `0`) |
| 시그니처 표시 | 줄 끝 `}` 앞에 `, best: true` 넣기 (빼려면 지우기) |

고친 뒤에는 `Ctrl + S`로 저장하고, 브라우저에서 `F5`로 새로고침하세요.

그 밖에 가게 이름, 영업시간, 전화번호, 색깔을 고치는 곳에도 "[고치는 곳]" 주석이 달려 있어요.

## 파일 구성
| 파일 | 설명 |
|---|---|
| `index.html` | 메뉴판 화면과 메뉴 정보 전부 |
| `qr.html` | 메뉴판 주소를 QR 코드로 만들어 주는 페이지 |
| `CLAUDE.md` | 이 프로젝트를 만들 때 지킨 작업 규칙 |
| `자료/기획시트.png` | 가게 정보와 메뉴를 정리한 기획시트 |

## 사용한 것
HTML, CSS, JavaScript만 사용했어요. 리액트 같은 복잡한 도구는 쓰지 않았어요.
(`qr.html`에는 QR을 그려 주는 오픈소스 도구 하나가 파일 안에 포함되어 있어요.)
